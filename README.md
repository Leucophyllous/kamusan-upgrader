# kamusan-upgrader

[KamuSan](https://www.kamusan.net/otoge/) のバージョン間で、自作譜面・スコア・設定などのユーザーデータを引き継ぐ非公式ツールです。
旧版 → 新版（アップグレード）も、新版 → 旧版（ダウングレード）も扱えます。

> 本リポジトリにゲーム本体・セーブデータ・譜面などは**含まれません**。ツール（Python スクリプトと bat）のみです。
> KamuSan の制作者・権利者とは無関係の個人ツールです。利用は自己責任でお願いします。

## 必要なもの

- Windows と Python 3（標準ライブラリのみ。GUI は tkinter を使うため、標準の Python インストーラーで入ります）

## フォルダ構成

スクリプトと同じ場所に、次のように置きます。

```
(任意のフォルダ)
├─ kamusan_upgrader.py
├─ 引き継ぎ実行.bat など
├─ 旧KamuSan\KamuSan\GamePro.exe ...
└─ 新KamuSan\KamuSan\GamePro.exe ...
```

`旧KamuSan` と `新KamuSan` の名前でなくても、GUI（`起動.bat`）または `--old` / `--new` でフォルダを指定すれば使えます。

## 使い方

| 操作 | 方法 |
|---|---|
| 旧 → 新へ引き継ぐ | `引き継ぎ実行.bat` をダブルクリック（内容が表示され、`y` で実行） |
| 新 → 旧へ引き継ぐ | `新から旧へ引き継ぎ.bat` |
| 直近の引き継ぎを取り消す | `元に戻す.bat` |
| 画面で確認しながら操作する | `起動.bat`（GUI） |

GUI では、元と先の入れ替え、プレビュー、実行、取り消し、「引き継ぎ先の自動更新を止める」のチェック切り替えができます。

コマンドで使う場合:

```bash
# 計画だけ表示（何も変更しない）
python kamusan_upgrader.py --old 旧KamuSan --new 新KamuSan --dry-run

# 実行（確認あり）
python kamusan_upgrader.py --old 旧KamuSan --new 新KamuSan

# スクリプトの隣の 旧KamuSan / 新KamuSan を使う（--reverse で向きを逆に）
python kamusan_upgrader.py --auto

# 取り消し
python kamusan_upgrader.py --auto --restore-latest

# 自動更新(オンライン通信)の停止 / 許可
python kamusan_upgrader.py --auto --update off
python kamusan_upgrader.py --auto --update on
```

## 引き継ぐもの

| 対象 | 既に引き継ぎ先にある場合 |
|---|---|
| `Save/`（セーブデータ） | **上書きしない**（元の内容は退避フォルダへ保存）。`--overwrite-save` で上書き |
| `score_*.csv`、`temp` | 引き継ぎ元の内容で上書き（元のファイルは退避） |
| `Data/ExData`、`Data/ExPict`、`Backup`（自作譜面など） | 引き継ぎ先に無いものだけ追加。同名で内容が違う場合は先を維持 |
| `Game.ini` | 両方にあるキーだけ引き継ぎ元の値を反映（他の行は変更しない） |

## 安全面

- 引き継ぎ元のフォルダは読み取りのみで、変更しません。
- セーブデータ(.sav)は中身を解析・改変せず、ファイルとして扱います。KamuSan の readme には解析・セーブデータの改造を禁止する旨があり、それに抵触しないようにしています。
- 引き継ぎ先で上書き・追加されるファイルは `_upgrade_backup/日時/` に退避し、`元に戻す` で復元できます。
- コピー後に SHA-256 で内容を検証します。
- `GamePro.exe` の起動中は実行しません。

### セーブについて

新しい版のゲームは、旧版のセーブを置いて一度起動すると、記録を保ったまま自動で変換します。
そのため、引き継ぎ先に変換済みのセーブがある場合はそれを上書きしない既定にしています。
新版のフォルダにセーブがまだ無ければ、旧版のセーブがそのままコピーされます。

## 自動更新の停止について

`Game.ini` の `Proxy=127.0.0.1` / `ProxyPort=9` を設定して、ゲームのネット通信を行き止まりに向けます。
**更新確認だけでなく、オンラインのランキング送信など、ゲームのネット通信すべてが止まります。**
チェックを外す（`--update on`）と、2行とも空に戻ります。最初の切り替えの前に `Game.ini.upgrader_bak` へ元の内容を保存します。

## 動作確認の範囲

ver.1.37 → ver.1.55 の引き継ぎで、記録の引き継ぎ・選曲画面への表示・取り消しを確認しています。
実際の演奏、お気に入り、ランキング送信は試していません。
